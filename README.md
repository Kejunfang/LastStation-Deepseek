## 这是一个怎样的故事？

八月的最后一周，你回到海边小镇汐见町，准备处理外婆留下的旧屋。

镇上的人都说，白鹭灯塔已经十年没有亮过了。
可在你回来的第一个夜晚，灯塔顶端亮起了一点微弱的金色光。

你爬上灯塔，遇见了一个不该存在于此的少女。
她叫汐崎灯。她好像认识你，而你完全不记得她。

这个夏天，你只有几天时间，找回八段被海雾藏起来的记忆，
然后决定：是让灯塔继续沉睡，还是让它再一次照亮这座小镇。

## 你会玩到什么

- 约 **20–35 分钟**的一周目，**4 个结局** + 二周目「第二个夏天」
- **8 段记忆碎片**、羁绊值、跨周目继承
- 手绘像素风小镇地图，自由选择每天要去的地方
- 旧收音机调频小游戏，三段信号拼出十年前的真相
- 6 个手动存档 + 自动存档、历史记录、自动播放、快进
- 记忆画廊、结局画廊、手记、设置
- 所有画面都由代码实时绘制，没有图片素材

## 怎么玩

| 操作 | 说明 |
| --- | --- |
| 点击对话框 / 空格 / 回车 | 推进对话；文字没显示完时先补全 |
| 按住 Ctrl | 快进（默认只跳过已读文本） |
| 数字键 1–4 | 选择选项 |
| Esc | 关闭面板；游戏中打开菜单 |
| 右上角快捷栏 | 记录 / 自动 / 快进 / 存档 / 读档 / 手记 / 设置 / 菜单 |
| 地图 | 点击光点前往地点；每个地点只能去一次 |
| 收音机 | 拖动刻度或按 ← → 调频，Enter 锁定信号 |

## 常见问题

**打开后没有声音？**
先点击一下画面，再检查系统/浏览器音量。首次进入时背景音乐可能需要几秒加载。

**手机上字太小？**
请横屏游玩。竖屏时游戏会提示旋转屏幕。

**存档在哪里？**
存档保存在当前浏览器的本地存储里。换浏览器、清理网站数据或使用无痕模式后，存档不会保留。重要进度请使用游戏里的手动存档。

**可以跳过对话吗？**
可以。右上角的「自动」会按设定速度播放；「快进」只跳过已读文本。按住 Ctrl 也可以临时快进。

**第一次玩，需要看攻略吗？**
不需要。跟着直觉选择就好。四个结局和隐藏的真结局都值得自己走一遍。

**这个页面需要联网吗？**
线上版需要联网加载页面和音乐。也可以把仓库下载到本地，用本地服务器离线游玩。

## 结局条件（剧透）

<details>
<summary>点开查看四个结局的达成条件</summary>

- **A 长夜**：最终选择「让灯塔继续沉睡」。
- **B 归港**：羁绊 ≥ 7，最终选择「点亮灯塔」。
- **C 回航**：完成收音机三段信号、本周目至少 7 段记忆，最终选择「回到十年前」。
- **TRUE 长明**：通关过 C（解锁二周目）、累计集齐八段记忆、本周目羁绊 ≥ 9，最终选择金色的第四条路。
